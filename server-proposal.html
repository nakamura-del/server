03 / リスク詳細

人事考課データは給与査定にも関わる 機密性の高いデータ です。WordPress と同じサーバーに置くことの具体的なリスクは以下です。

▲ 想定される障害シナリオ

WordPress のプラグイン脆弱性は毎月のように発見されており、攻撃者の標的になりやすい構成です。一度サーバーに侵入されると、同じサーバー内の全データにアクセス可能になります。

WordPressの脆弱性発覚 → サーバー侵入 → 人事評価データ流出

VPS で分離すれば、仮に WordPress 側で問題が起きても人事システムは無影響です。
